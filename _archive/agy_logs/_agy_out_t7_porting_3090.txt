## 2. Decisioni Chiave di Porting

1. **Centralizzazione Path (`paths.py`)**:
   - `local3090` (default su host/Docker): cartella root `~/gemma-4-omni` (o `/workspace`), con sottocartelle `data/`, `checkpoints/`, `samples/`, `logs/`, `qwen_subtalker/`, `code2wav_weights/`.
   - `kaggle`: preserva `/kaggle/working` e `/root/kaggle_big`.
2. **Separazione Dipendenze ADR-003**:
   - `qwen-tts 0.1.1` (`transformers==4.49.0`) e `unsloth` (`transformers>=5.x`) convivono senza conflitti grazie all'ambiente virtuale isolato `/opt/venv_phase1` dentro il container unificato. `run_3090.py --phase prep` delega automaticamente al runtime corretto.
3. **Hardening di Sicurezza Docker**:
   - Utente non-root `appuser` (`1000:1000`) per evitare file creati come `root` sui volumi host.
   - `--ipc=host` per allocazione condivisa di memoria PyTorch DataLoader (azzeramento errori `SIGBUS`).
   - Flag `--privileged` e `--network host` **mai utilizzati**.

## 3. Guida Attivazione per l'Operatore (Host `gpu3090`)

Quando la connessione SSH alla macchina 3090 e attiva:

### Passo 1: Connessione e Provisioning Host
```bash
ssh gpu3090
cd ~/gemma-4-omni
chmod +x setup_3090.sh docker_run_3090.sh
./setup_3090.sh
```

### Passo 2: Smoke Test di Validazione (Obbligatorio)
Esegue 4 batch di training per validare forward, backward, LoRA e coupling subtalker congelato:
```bash
./docker_run_3090.sh smoke
# oppure via Docker Compose:
docker compose run --rm train-smoke
```

> **Verifica Numerica Gate**: La loss iniziale a passo 0 deve essere compresa tra **13.0 e 17.0** ($\log 4096 + \log 2048$). Se collassa a $<1.0$ o supera $19.0$, interrompere l'esecuzione.

### Passo 3: Comandi Operativi Standard
```bash
# Training completo Fase 2:
./docker_run_3090.sh train

# Preprocessing dati Fase 1 (se si vogliono rigenerare i Parquet su 3090):
./docker_run_3090.sh prep

# Valutazione checkpoint e generazione campioni audio in samples/:
./docker_run_3090.sh eval

# Avvio Server REST FastAPI (porta 8000):
./docker_run_3090.sh serve

# Shell interattiva non-root:
./docker_run_3090.sh bash
```

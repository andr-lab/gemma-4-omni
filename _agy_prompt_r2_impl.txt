### 4.1 Adapter MLP residuale (variant=2)
Definisci a livello di MODULO (fuori dal blocco `if STAGE2...`, ad es. subito prima della sezione STAGE2) una factory riutilizzabile:

```python
def build_ht_adapter(_hid, variant=1):
    if variant == 2:
        # MLP residuale: LayerNorm( MLP(h) + skip(h) ), ~11M params
        return nn.Sequential(
            nn.Linear(_hid, 3072),
            nn.SiLU(),
            nn.Linear(3072, 2048),
            nn.LayerNorm(2048),
        ).to(...)  # fp32
    return nn.Sequential(nn.Linear(_hid, 2048), nn.LayerNorm(2048)).to(...)  # R1, invariato
```

ATTENZIONE alla forma esatta: la skip-connection DEVE sommare l'ingresso proiettato. Il design approvato e':
```
h_proj = Linear_1536x2048(h)                      # proiezione dello skip
h_mlp  = Linear_3072x2048(SiLU(Linear_1536x3072(h)))
h_out  = LayerNorm_2048(h_mlp + h_proj)           # somma prima della LayerNorm
```
Realizzalo come un modulo nn.Module dedicato (classe `ResidualAdapter`) con i sotto-moduli nominati, NON come un nn.Sequential che perderebbe la somma residuale. Deve essere serializzabile con state_dict (torch.save) e ricaricabile.

### 3.5 Meccanismo di ammissione cooperativa in `duplex_kernel/engine.py`
Nel codice di `duplex_kernel/engine.py`:
```python
def admit_listener(phase: str, site: str) -> None:
    if (
        prioritized_v2_talker
        and phase == "talker"
        and site in {"subtalker", "next_qwen_model"}
    ):
        return
    started = time.perf_counter() if cuda_timing_enabled else 0.0
    self._wait_for_listener_admission(
        listener_admission_wait, metrics, phase
    )
```
Notice: quando `prioritized_v2_talker` è true, `admit_listener` esce immediatamente con `return` sia su `subtalker` sia su `next_qwen_model`!
Viene chiamato con effetto reale solo su `codec_head` (una volta ogni 80 ms).
Tra un frame codec e l'altro, il Talker esegue SubTalker (13 ms) e lo step Qwen Q1 (25-34 ms) senza cedere il passo o verificare la coda del listener.

Inoltre, in `duplex_kernel/server_pcm_tracker.py`:
```python
def _wait_for_listener_backlog_admission(
    queue_depth: Callable[[], int],
    generation_is_current: Callable[[], bool],
    *,
    callbacks_active: bool = False,
    max_wait_s: float = 0.160,
    poll_interval_s: float = 0.0005,
    now: Callable[[], float] = time.monotonic,
    sleep: Callable[[float], Any] = time.sleep,
) -> ListenerBacklogAdmission:
    ...
    while True:
        if not generation_is_current():
            return ListenerBacklogAdmission.ABORTED
        if queue_depth() <= 1:
            return ListenerBacklogAdmission.ADMITTED
        remaining = deadline - now()

```
La condizione controlla `queue_depth() <= 1` (dove queue_depth è `sess.audio_ingress.qsize`), con timeout fino a 160 ms.

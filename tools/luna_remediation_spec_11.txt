## 1. File: `duplex_kernel/engine.py`

### 1.1 Vectorize `_postprocess(wav)` (around lines 7436-7443)
In `PipelineEngine._postprocess(wav: np.ndarray) -> np.ndarray`:
Replace the slow Python list comprehension loop:
```python
        frame_samples = max(1, int(round(0.020 * sample_rate)))
        frame_rms = np.asarray(
            [
                np.sqrt(np.mean(np.square(signal[offset : offset + frame_samples], dtype=np.float64)))
                for offset in range(0, signal.size, frame_samples)
            ],
            dtype=np.float64,
        )
```
with a fully vectorized 2D NumPy reshape calculation that computes exact mathematical RMS across `axis=1`:
```python
        frame_samples = max(1, int(round(0.020 * sample_rate)))
        n_full_frames = signal.size // frame_samples
        if n_full_frames > 0:
            full_signal = signal[: n_full_frames * frame_samples].reshape(n_full_frames, frame_samples)
            full_rms = np.sqrt(np.mean(np.square(full_signal, dtype=np.float64), axis=1))
            rem = signal.size % frame_samples
            if rem > 0:
                rem_rms = np.asarray([np.sqrt(np.mean(np.square(signal[n_full_frames * frame_samples :], dtype=np.float64)))], dtype=np.float64)
                frame_rms = np.concatenate([full_rms, rem_rms])
            else:
                frame_rms = full_rms
        elif signal.size > 0:
            frame_rms = np.asarray([np.sqrt(np.mean(np.square(signal, dtype=np.float64)))], dtype=np.float64)
        else:
            frame_rms = np.zeros(0, dtype=np.float64)
```
Preserve all subsequent logic (noise floor, tail samples, cosine fades, target RMS normalization) exactly as-is.

## 2. File: `duplex_kernel/response_event_ledger.py`

### 2.1 Avoid unnecessary `self.project()` in `record_pcm_consumed` (around line 847)
In `ResponseEventLedger.record_pcm_consumed()`:
Currently:
```python
                if on_commit is not None:
                    on_commit(self.project())
```
`self.project()` rebuilds the entire projected history from source tokens on every single client PCM consumption ACK (which arrives every 10 ms). The callback in `server_pcm_tracker.py` is `commit_branch_ack(_projection: Any = None) -> None`, which completely ignores `_projection`.
Update lines 847-848 to:
```python
                if on_commit is not None:
                    try:
                        on_commit()
                    except TypeError:
                        on_commit(self.project())
```
This ensures zero overhead when the callback does not require a projection, while maintaining 100% backward compatibility for callbacks that do.
